Overview
This excercise explores the MaxCoverage and MaxInfluence instances 2100-2203 with a uniform constraint using two evolutionary algorithms:
- population-based single-objective EA (SOEA) with repair and diversity mechanisms. 
- population-based multi-objective EA (MOEA) bacting on value and -cost objectives.
Each algorithm is evaluated for population sizes 10, 20, 50, with 30 independent runs and a budget of 10,000 fitness evaluations per run.


Single object evolutionary algorithm (SOEA)
The SOEA aims to maximise solution value while maintaining feasibility.
Each candidate is represented as a bitstring, with the IOH submodular objective used directly for evaluation.
Negative fitness values indicate infeasible solutions that exceed the cost limit.

Feasibility Handling
We used marginal-drop repair, which iteratively removes the item with the smallest marginal contribution until the constraint is satisfied.
This approach preserves high value elements and leverages the submodular property of diminishing returns.
An earlier random-drop variant was discarded after showing slower and less stable convergence.

Diversity and Selection
To balance exploration and exploitation, we combined deterministic crowding (offspring competes with the more similar parent)
and a mild fitness-sharing step that occasionally replaces the most crowded individual with a random immigrant.
This maintains diversity without slowing convergence.

Rationale
SOEA’s marginal-repair mechanism provides a simple yet powerful way to enforce feasibility efficiently, enabling faster progress within limited evaluations while maintaining population diversity.


Multi objective evolutionary algorithm (MOEA)
The MOEA extends the search to optimise both value and cost simultaneously, using a lightweight NSGA-II framework.
Like SOEA, individuals are bitstrings, but the algorithm tracks two objectives, maximise coverage/influence and minimise cost.

Diversity and Selection
Individuals are ranked using fast non-dominated sorting, and crowding distance ensures diversity within each front.
Tournament selection based on rank and crowding favours both high-quality and well-spread solutions.
Mutation follows the same 1/n bit-flip rate as SOEA, with no crossover.

Rationale
The MOEA complements SOEA by exploring the Pareto front and capturing trade-offs between value and cost.
However, the absence of explicit repair means feasibility emerges more slowly, especially for larger populations, reflecting the trade-off between diversity and convergence speed.
